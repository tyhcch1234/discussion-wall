# 討論牆 Discussion Wall

一個類似 **Padlet** 的網上討論牆：開一條連結，任何同學都可以把答案貼上牆，所有人即時看到。
純前端單檔（`index.html`），可直接放在 GitHub Pages。

🔗 **網址**：https://tyhcch1234.github.io/discussion-wall/

---

## 功能

| 功能 | 說明 |
| --- | --- |
| 多人共用 | 貼上的卡片會同步到雲端，所有開着頁面的人都看得到（每 12 秒自動更新，切換分頁回來即時更新） |
| 多個討論板 | 上方分頁可開不同題目，例如「Q1」「Q2」「自由分享」 |
| 彩色卡片 | 6 種顏色，方便分類不同意見 |
| 讚好 | 同學可以按 ❤️ 表達支持，可依「最多讚」排序 |
| 匿名 | 貼文時勾選「匿名」，只顯示「匿名」 |
| 名字記憶 | 名字只存在自己裝置（localStorage），不用註冊、不用登入 |
| 管理員 | 輸入密碼後可新增／改名／刪除討論板、刪除任何卡片、匯出／匯入備份 |
| 日／夜模式 | 自動跟隨系統，也可手動切換 |
| 深層連結 | `#b=<板ID>`，可直接分享某一塊板 |

## 使用流程

1. 老師把網址傳給學生（頁面右上「🔗 分享」會複製當前討論板的連結）。
2. 學生第一次進入先按右上角名字改做自己的名字。
3. 在底部輸入答案 → 揀顏色 → 按「貼上牆」。
4. 老師按右上 ⚙️ 輸入管理密碼 → 可開新討論板、刪除不當卡片、匯出備份。

**預設管理密碼：`teach2026`**
密碼寫在 `index.html` 最上方的 `CONFIG.ADMIN_PASS`，請自行修改（改完 commit + push 即生效）。

> ⚠️ 密碼寫在前端程式碼中，只適合課堂「防止誤刪」，不是真正的帳戶安全機制。任何知道網址的人都仍然可以貼文。

## 資料儲存

預設使用免費雲端 [kvdb.io](https://kvdb.io)（`CONFIG.KVDB_BUCKET`），所以**不需要後端、不需要資料庫**就能跨裝置共用。

若雲端連不上，頁面會自動切換到「本機模式」（只儲存在該裝置），並在頂部顯示提示。

### ⚠️ 重要：免費 bucket 有期限

此專案的 bucket 是以匿名方式建立，未驗證 email 的免費 bucket 資料會在建立後約 **30 天**失效。
若要長期使用（整個學期），建議二選一：

**A. 匯出備份（最簡單）**
管理員 → ⚙️ → 「匯出備份」下載 JSON；需要時再「匯入備份」。

**B. 換成永久免費的 Firebase（建議，5–10 分鐘）**
1. 到 <https://console.firebase.google.com> 建立專案 → 新增「Realtime Database」→ 測試模式。
2. 專案設定 → 一般 → 你的應用程式 → 取得 `databaseURL`。
3. 把 `index.html` 內 `makeCloudStore()` 換成 Firebase REST 版本（或把 bucket 換成已用 email 驗證的 kvdb bucket），再 push 即可。

需要的話可以請 AI 幫你把 Firebase 版本接上，只需提供 `databaseURL`。

> 🔒 隱私：這是公開的課堂討論板，bucket id 寫在原始碼中，任何拿到網址的人都能讀寫；請勿張貼個人敏感資料。
